# Templates reutilizáveis

Todos os valores são fictícios. Copiar para um projeto novo e preencher somente com metadados não sensíveis.

- [Arquivo de ambiente de exemplo](.env.example) — nomes de variáveis e placeholders.
- [Manifesto do projeto](project-manifest.yaml) — projeto, ambientes, owners e elegibilidade.
- [Checklist de novo projeto](new-project-checklist.md) — checklist de bootstrap.
- [Registro de decisão](decision-record.md) — decisão arquitetural.

Não versionar .env.local, secrets, connection strings reais, tokens, dumps ou dados de clientes.
