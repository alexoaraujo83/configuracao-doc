# Pesquisa das fontes oficiais

Esta seção registra o escopo de pesquisa e os pontos de referência para a documentação dos fornecedores. A documentação oficial é dinâmica: antes de aplicar qualquer procedimento, confirme a página, versão, disponibilidade por plano e data de consulta.

## Fontes primárias

- GitHub Docs (português): https://docs.github.com/pt
- Auth0 Docs: https://auth0.com/docs
- Vercel Docs: https://vercel.com/docs

## Método

1. Usar a documentação oficial do produto como fonte normativa.
2. Navegar por conceitos, procedimentos, referência de API/CLI, segurança e limites de plano.
3. Registrar diferenças entre capacidade documentada e recurso disponível no plano/conta do projeto.
4. Validar instruções no ambiente não produtivo antes de recomendar execução em produção.
5. Registrar data de consulta, versão do SDK/CLI, plano e evidência para cada configuração verificada.
