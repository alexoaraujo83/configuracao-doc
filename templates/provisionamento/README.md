# Templates de provisionamento — Free

Estes arquivos são modelos não secretos para iniciar projetos com Next.js + TypeScript + Auth0 + Neon + GitHub + Vercel.

## Conteúdo
- [project.yaml](./project.yaml): manifesto declarativo de recursos e ambientes.
- [.env.example](./.env.example): nomes de variáveis e placeholders.
- [checklist.md](./checklist.md): roteiro de revisão e aceite.

## Uso
1. Copie a pasta para o novo repositório ou use os arquivos como referência.
2. Preencha os identificadores não secretos.
3. Mantenha status como `planned` até haver evidência.
4. Guarde os valores reais em local apropriado, nunca no manifesto ou no Git.
5. Adapte os campos à arquitetura e aos limites Free confirmados para o projeto.

Estes templates não criam recursos nem executam provisionamento.
